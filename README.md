# CloudPulse 🚀

CloudPulse is an end-to-end DevOps project that demonstrates how to build, containerize, deploy, and automate a cloud-hosted Python application.

## Features
- Flask web application
- Docker containerization
- AWS EC2 deployment
- CI/CD with GitHub Actions
- Automated redeployment on every push

## Tech Stack
- Python
- Flask
- Docker
- AWS EC2
- GitHub Actions
- Linux (Ubuntu)

## Project Workflow
1. Build Flask app locally
2. Containerize with Docker
3. Deploy to AWS EC2
4. Push code to GitHub
5. Trigger GitHub Actions
6. Auto-deploy updated version to EC2

## Live Deployment
CloudPulse is deployed on AWS EC2 and updated automatically through CI/CD.
